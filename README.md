# AI Free

Крутой Android-проект: личный ИИ-помощник с чатом, голосовым вводом, озвучкой, фото-вложениями, памятью и подключением AgentRouter.

## Возможности

- Уникальный тёмный дизайн с градиентом и карточками.
- Чат с ИИ через AgentRouter.
- Demo-режим без токена.
- Выбор моделей:
  - `gpt-5.6-sol`
  - `claude-opus-5`
  - `claude-opus-4-8`
- Голосовой помощник:
  - кнопка микрофона;
  - распознавание речи;
  - озвучка ответа.
- Фото в проекте:
  - кнопка выбора изображения;
  - отправка фото как вложения в чат;
  - заготовка под анализ изображения.
- Память помощника.
- Быстрые команды: идея, план, код, анализ фото.

## Как собрать APK

```bash
flutter pub get
flutter build apk --release
```

Готовый APK будет здесь:

```text
build/app/outputs/flutter-apk/app-release.apk
```

## Настройка API

В приложении открой `Настройки`, вставь AgentRouter token и выбери модель.

Base URL по умолчанию:

```text
https://agentrouter.org/v1/chat/completions
```

Токен в код не вставлен специально — так безопаснее.


## Сборка APK через GitHub Actions

Я добавил автоматическую сборку APK. Инструкция находится в файле:

```text
GITHUB_BUILD_INSTRUCTION.md
```

Коротко:

1. Загрузи проект на GitHub.
2. Открой вкладку **Actions**.
3. Запусти **Build AI Free APK**.
4. Скачай готовый APK из **Artifacts**.
